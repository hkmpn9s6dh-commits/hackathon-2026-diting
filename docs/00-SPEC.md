## 2. 黄金路径（评委怎么看到它）

1. 评委打开投稿邮件 → 看到 **A3 三视图展示页**（一张图说清：是谁、三个角度、几个颜色、一句记忆点）。
2. 点开 **15 秒白底动效** → 看见它「听见了什么」：耳朵转、眼睛睁、跳一下。
3. 读 **800–1500 字形象介绍** → 名字的来历、耳朵为什么是钟、能怎么用（导览/文创/短剧）。
4. 若入围 → 第二轮用它拍 2–5 分钟短片。

三件交付物必须互相印证：**图上有的，文字里要说得出理由；文字里说的，动效里要看得见。**

## 3. 作品定义

- 名字：**青听**（Qīngtīng）——「青」是青阳、青阳腔、九子岩的青绿；「听」是谛听的本职。
  两个字连读就是「倾听」。
- 一句话：**一只把耳朵长成两口钟的小谛听，蹲在七布泉边练习听。**
- 记忆点（只有一个）：**耳朵是两口钟**——听见什么，钟就轻轻响一下。
- 形态：幼兽（幼体比例，头身比 1:1.4），坐姿，独角短如石笋，闭眼，额上一枚朱砂点。
- 色彩：青灰（岩）、苔青（苔）、朱砂（印）、铜金（钟）、米白（腹/口鼻）。

## 4. 验收条件（可判定）

| 编号 | 条件 | 判据（机器可查） |
| --- | --- | --- |
| AC-1 | 三视图同源 | front/side/back 三个视图的**投影高度**与**投影宽度**由同一 rig 正交投影得到，高度差 ≤ 0.5 px，宽度按视图几何关系给出（侧视宽 = 体深，正视宽 = 体宽），断言写在 `tests/test_views.py` |
| AC-2 | 不裁切 | 每个视图的 bbox 落在画布内，四边留白 ≥ 4% 画布边长 |
| AC-3 | 调色板受控 | 展示页中面积占比 ≥ 1% 的颜色 ≤ 9 种 |
| AC-4 | 缩略图可辨 | 1500 px 轮廓缩到 300 px 再放大回 1500 px，与直接 300 px 渲染的轮廓 IoU ≥ 0.97；且 300 px 下「双钟耳 + 独角 + 朱砂点」三项特征由 `tests/test_silhouette.py` 的位置断言守住 |
| AC-5 | 动效时长与画幅 | 15.00 s ± 0.05，1080×1080，30 fps |
| AC-6 | 素色白底 | 四角 40×40 像素块均值与纸白 `#FBFAF7` 每个通道差 ≤ 3（视频压缩会让它掉 1–2 级） |
| AC-7 | 有声音轨 | MP4 含 AAC 音轨；整体响度 −20 ~ −14 LUFS |
| AC-8 | 介绍字数 | 汉字数 800–1500（`scripts/check_text.py`） |
| AC-9 | 确定性 | 连续两次 `build.py`，全部 PNG 的 sha256 相同 |
| AC-10 | 全新 clone 可复现 | 新 clone 里 `bash scripts/verify.sh` 退出码 0，且不依赖本机任何未入库文件 |

## 5. 不做什么

- 不做 3D 打印件、不做实体手办渲染图（无实拍素材，容易变成「假实物」）。
- 不做第二轮 2–5 分钟视频（要等入围名单）。
- 不用生图模型直接出图：本作品的角色必须**可参数化重建**，否则三视图的一致性无从证明。
  文生图只允许用于找参考、不进入交付物（见 `docs/02-DESIGN.md` §5）。
- 不在介绍里写「必将获奖」一类的话。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 三视图各画各的，同一个角色三个样 | 不用手绘：先建 3D 椭球 rig，三个视图都是它的正交投影（AC-1 锁死） |
| 球体堆叠读成「一堆气球」 | 统一描边（外轮廓 3 px）+ 单一材质 + 只留 5 色；缩到 300 px 检查 |
| 谛听的文化符号被做丢 | 独角、善听（闭眼/钟耳）、地藏道场（九华山）三样写进造型说明 |
| 「素色白底」被做成有背景的短片 | 背景恒为 #FBFAF7，动效只允许角色与极淡的声波弧 |
