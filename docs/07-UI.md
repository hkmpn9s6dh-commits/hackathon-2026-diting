# 07 · UI / 视觉规格（闸 A 第 1–4 节）

## §1 风格预设

**预设名：`kiln-paper`（纸上窑火 · 单色版）** —— 这一版按「印刷纸 + 单色印」的思路做，不是屏幕 App。

- 底：暖白 `#FBFAF7`（纸），不在白底上叠色块；分隔只用 1 px 线 `#D9D2C5`。
- 字：标题 Noto Serif SC（思源宋体）600；正文与标注 Noto Sans SC 400；数字用等宽 `tabular-nums`。
- 主色：青灰 `#6E7F79`；辅：苔青 `#48604F`、朱砂 `#B8402C`、铜金 `#A9803C`、米白 `#EFE7D8`。
- 全部颜色只从这 5 个里取，不引入第 6 个有彩色。
- 版面：左 62% 放三个视图（同一基线、同一比例），右 38% 放身份信息；底部一条 4 色色卡。

**为什么是这套**：文旅 IP 的交件会被打印、会被贴在展板上、会被缩成微信头像。
纸上单色系统最抗缩、最抗打印偏色，也最像「文旅局会用的东西」。

## §2 尺子（外部参考，每件写学哪一点）

首届赛事没有往届得奖作，尺子取同品类（华人市场、文旅/品牌吉祥物）的成熟 IP。**只看造型方法，不抄元素。**

| # | 作品 | 出处 | 学哪一点 |
| --- | --- | --- | --- |
| R1 | 冰墩墩（2022 北京冬奥） | https://www.beijing2022.cn/ | **一层"壳"改写轮廓**：熊猫谁都会画，冰壳让它变成别人。单一材质 + 单一高光，缩到 32 px 仍认得出 |
| R2 | 雪王（蜜雪冰城） | https://www.mxbc.com/ | **极简剪影 + 一个动作**：王冠 + 冰淇淋，两个凸起就够；全身上下不超过 3 个颜色 |
| R3 | 玲娜贝儿（迪士尼） | https://www.disney.com/ | **超比例**：耳朵和尾巴大到不合解剖，反而成了识别；粉色系靠一处深色（眼/鼻）压住，不然会糊 |
| R4 | MOLLY（泡泡玛特） | https://www.popmart.com/ | **一个表情定人格**：噘嘴 + 大眼睛，不靠剧情；大头小身，方便做成系列 |
| R5 | 故宫脊兽（文创化） | https://www.dpm.org.cn/ | **把建筑构件变成角色**：纹样是它的"衣服"，不是贴上去的贴纸 |
| R6 | 熊本熊 | https://www.kumamon.com/ | **靠"缺陷"记忆**：笨拙比例 + 两团红腮；不完美比完美更像活物 |

**从尺子里抄下来的四条做法**（写进 `docs/02-DESIGN.md`）：

1. 先定**一个**超过解剖学的比例（这里选耳朵），其余全部收敛。
2. 颜色 ≤ 5，其中 1 个只用在 1 个地方（朱砂点只出现在额头）。
3. 轮廓必须在 300 px 下能说出「两个钟 + 一个角」。
4. 表情只做一个常态（闭眼听），情绪变化交给耳朵。

## §3 一个记忆点

**耳朵是两口钟。**

- 正视：左右各一口倒扣的钟，钟口朝外下方，钟身有一道铜箍。
- 侧视：只看见一口钟的侧面轮廓 + 钟口的一小段弧。
- 背视：两口钟的背面，铜箍成为两道横线。
- 动效里：听见声音时，左耳先转 25°，钟口轻轻晃一下（钟不动，只有箍和钟舌动）。

这一条同时承担三件事：文化（钟=声=听）、识别（300 px 剪影）、延展（周边可以做成一摇就响的挂件）。

## §4 主屏规格（A3 展示页）

- 画布：3508 × 2480 px（A3 横版 300 dpi），出血不留，四边安全边距 120 px。
- 栅格：12 栏，栏宽 240 px，槽 24 px。左 8 栏（视图区），右 4 栏（信息区）。
- 字号：主标题 132 px / 副标 46 px / 视图标签 34 px（字距 +0.18em）/ 正文 26 px / 色卡注 22 px。
- 三个视图：同一基线 y=1780，同一比例（1 世界单位 = 760 px），间距 ≥ 160 px。
- 视图标签：`正視 FRONT` / `側視 SIDE` / `背視 BACK`，放在每个视图正下方 60 px。
- 信息区自上而下：名字（132 px）→ 读音与一句话（46/30 px）→ 记忆点（34 px 加粗 + 正文两行）
  → 色彩（4 个 88×88 色块 + hex）→ 出处一行（22 px，灰）。
- 底部：一条 1 px 线 + 左右两端的小字（左：赛事名；右：作者与日期）。
- 禁则：正文不得压在图形上（`data-noimg` 断言）；任何文字不进入视图 bbox。

## §5 动效规格（15 s）

- 画布 1080×1080，30 fps，450 帧；背景 `#FBFAF7` 纯色，不加渐变、不加网格。
- 节拍：
  | 时间 | 事件 |
  | --- | --- |
  | 0.0–2.5 | 呼吸（身体 ±1.2%），耳朵微颤 |
  | 2.5–4.5 | 左边来了一声：左耳外转 25°，头偏 6° |
  | 4.5–6.0 | 睁眼（闭眼弧 → 瞳孔），头转向左前 12° |
  | 6.0–8.0 | 跳一下（离地 6%，落地压缩 4%），颈铃摆 |
  | 8.0–11.0 | 两道极淡的声波弧从钟口扩散 |
  | 11.0–13.0 | 收势：耳回正，眼闭 |
  | 13.0–15.0 | 尾尖卷一下，回到起始帧（首尾可循环） |
- 首尾帧必须一致（可无缝循环），由 `tests/test_motion.py` 断言。
