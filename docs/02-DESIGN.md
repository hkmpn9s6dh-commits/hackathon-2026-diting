# 02 · 造型说明（为什么是这些形状）

## 1. 从尺子里抄下来的四条（对应 `docs/07-UI.md` §2）

1. **只放大一个比例**：耳朵。耳高占全高约 0.30、耳宽 0.26，是头宽的 0.9 倍。
   其余全部收敛——角短、腿短、身圆。
2. **颜色 5 个，其中一个只出现在一个地方**：朱砂只用在额上那一点，全画面没有第二处红。
3. **300 px 必须说出「两个大耳 + 一个角 + 一点红」**：见 `out/_thumb300.png` 的检查。
4. **只做一个常态表情**：闭眼。情绪交给耳朵，不交给脸。

## 2. 三视图为什么是这么来的

角色 = 一组带姿态的三维椭球 + 扫掠管 + 薄片：

| 部位 | 图元 | 参数 |
| --- | --- | --- |
| 头 / 身 / 四肢 / 口鼻 | 椭球（可旋转） | 中心、三轴半径、欧拉角 |
| 耳（薄片） | 平面多边形 + 边缘管 | 长度 0.30、半宽 0.128、外倾 24°、上仰 61° |
| 耳上的七道水纹 | 面内折线 | 7 条，沿耳长方向 0.14→0.84 |
| 独角 / 尾巴 / 耳缘 / 钟箍 | 变径扫掠管 | 折线 + 逐点半径 |
| 闭眼 / 嘴 | 屏幕空间折线 | 世界坐标采样后投影 |

投影是**正交投影**：Σ₂ 取 `R·diag(r²)·Rᵀ` 在视图平面上的 2×2 子块，
再做 Cholesky 得 L，边界就是 `c + L·(cosθ, sinθ)`。
所以「三视图一致」不是画得像，而是**同一个二次曲面的三个投影**——由 `tests/test_views.py` 断言。

## 3. 为什么不做生图

生图能出一张好看的图，但下一次要侧面、要动起来、要改耳朵大小，就得重新抽卡，
三张图之间的一致性无法证明。这场比赛的交付物恰好是**三视图 + 动效**，
一致性就是评分隐含的第一条。所以选择参数化重建，把「一致性」变成可执行的东西。

生图在本项目里只做了一件事：找参考（没有进入交付物）。

## 4. 三个变体（闸 D 的盲排材料）

| 变体 | 耳长 | 外倾 | 读起来 |
| --- | --- | --- | --- |
| A（定稿候选） | 0.30 | 61° | 中性、向上听 |
| B | 0.26 | 55° | 耳更小更平，偏「乖」 |
| C | 0.33 | 69° | 耳更大更竖，偏「警觉」 |

三者只差耳朵——因为**记忆点就是耳朵**，比三版更要保证其他部位不动。

## 5. 已知取舍

- 侧视只剩一只耳（另一只被头挡住）。这是薄片耳的必然结果，换成正视图里的「两只都在」会牺牲侧视的真实感。**保留真实感。**
- 背视里尾巴是一枚卷，读起来像「年轮」而不是「泉」。它的作用是提示"尾巴在动"，不承担识别。
- 闭眼在小尺寸下可能被读成眉毛——`out/_thumb300.png` 是专门用来盯这一条的检查图。
