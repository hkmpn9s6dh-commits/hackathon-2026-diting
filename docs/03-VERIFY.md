# 03 · 怎么验（闸 C）

## 一条命令

```bash
bash scripts/verify.sh
```

它会依次做六件事，任何一条失败退出码非 0：

| 步 | 内容 |
| --- | --- |
| 1 | `python -m unittest discover -s tests`：27 条断言 |
| 2 | 交付物存在性与尺寸（A3 3508×2480；三张 1500×1500；mp4/gif/pdf 存在） |
| 3 | `ffprobe`：1080×1080、30fps、450 帧、15.000 s |
| 4 | 展示页调色板：面积 ≥1% 的颜色 ≤ 9 |
| 5 | 介绍字数：800–1500 汉字 |
| 6 | 汇总 |

## 断言清单

### `tests/test_geom.py`（10 条）
投影数学本身：球在任何视图都是圆；椭球的三轴对应到视图宽高；旋转 90° 交换正视与侧视；
背面视图的深度方向相反；`sort_parts` 远的先画。

### `tests/test_views.py`（7 条）
- 三个视图**高度完全相同**（差 < 0.5 px @760）——这是「同一份 rig」的硬证据。
- 三个视图**最低点在同一条线上**。
- 正视与背视等宽；侧视比正视窄。
- 只用登记过的 6 个颜色。
- 三个耳朵变体必须真的不同（否则盲排没有意义）。

### `tests/test_deliverables.py`（10 条）
- 介绍 800–1500 汉字；不含「必将获奖」这类话；名字与记忆点一致。
- 视频 15.00±0.05 s、1080×1080、30/1、有 AAC 音轨。
- 抽第 0.2 s 一帧，四角均值与纸白 `#FBFAF7` 每通道差 ≤ 3（视频压缩会掉 1–2 级，所以不用「≥250」这种会被压缩打败的判据）。
- 展示页 3508×2480；三张视图 1500×1500 且四角 alpha=0。

## 确定性（AC-9）

同一份代码跑两次 `build.py`，四张 PNG 的 sha256 必须相同。
实测：本机与全新 clone 各跑一次，四张图 **逐字节一致**（见 `docs/04-PROOF.md`）。

## 已知不验的

- 不验「好不好看」——那是闸 D 的事，量测不判审美。
- 不验真机预览（微信/抖音里缩略图的效果）：本轮交付走邮箱，不经过平台压缩。
