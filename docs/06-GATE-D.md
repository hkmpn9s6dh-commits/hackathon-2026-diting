# 06 · 闸 D：盲排（预先登记的判据与做法）

## 为什么不是「和往届得奖作混排」

这场大赛是**首届**，没有任何往届得奖作品。父单的闸 D 判据（成品与 ≥5 件往届得奖作混排，
每位评委都要把它排在 ≥3 件得奖作之上）在这里**无法照抄**。

上一轮（赛道 W）遇到同样情况时记下的教训是：**尺子要对齐媒介与画幅**。
所以这一轮用两条代理判据，**在看结果之前写下来**：

| 判据 | 内容 | 过线 |
| --- | --- | --- |
| P1 同题 | 同一角色三个版本（耳的大小与角度不同）A/B/C，3 位不同家族的评委会各自排序 | 定稿版至少被 **2 位**排在第 1 |
| P2 外部参照 | 定稿版与 5 个已成名的华人市场 IP 主形象混排（6 张，随机字母） | 定稿版排进 **前 3 名**（即压过 3 张） |

- P1 与 P2 都满足 → **过线**。
- 只满足一条 → **条件性通过**，写明差在哪。
- 都不满足 → **未过线**，照「两轮就停」的规则停手交用户。

P2 只能说明"放在成名 IP 旁边会不会立刻掉档"，不能直接换算成"进得了终评"。
这一点写在结论里，不藏。

**第 1 轮：P1 未过（1/2）、P2 未过（两位都排第 5）。**

两人对耳朵角度意见相反（GLM 喜欢摊得最开的 A，GPT 喜欢最竖的 C），
但**对同一件事意见一致：这只兽太静、太端正，像一个标志，不像活的。**
GPT 还点了一句「横向耳朵让远看轮廓偏散」——说明耳的角度不是主要问题，**姿态**才是。

## 改法（第 2 轮之前）

只改「活气」，不动造型结构（记忆点、颜色、三视图同源都不动）：

1. **头歪 4.5°**，脸跟着偏 3°——不再像证件照。
2. **两耳不对称**：左耳外转 12°、右耳回 6°——像正在听左边。
3. **耳内七道水纹由苔青改铜金**、线宽 0.0072→0.0080：缩到 300 px 也读得出（记忆点不能只在放大时成立）。
4. 展示页、三视图、动效三处用**同一套姿态**（`rig/character.py` 的 `POSE`），避免图与片对不上。

## 结论：第 2 轮仍未过线，按「两轮就停」停手

| 判据 | 结果 | |
| --- | --- | --- |
| P1 同题 | R 拿到 1 个第一（GPT）、1 个第二（GLM） | ❌ 需 2 个第一 |
| P2 外部参照 | 第 4（GLM）、第 5（GPT） | ❌ 需进前 3 |

**但有两条是确定的**：

1. **两位评委都点名 R「最像活的」**，也都没把它排最后——第 1 轮「太端正、像标志」这条批评被改掉了。
2. **外部混排从第 5 升到第 4（GLM 那张）**，稳定压过雪王，但还压不过玲娜贝儿、冰墩墩、熊本熊。

**两人对 Q 的判断完全相反**（GLM 说 Q「最精神」排第 1，GPT 说 Q「动作感最弱」排第 3），
说明「把耳朵再竖一点」不是一个有共识的方向，所以定稿**不再合并 Q 的耳角度**，就用 R。

## 定稿

`out/` 里所有交付物都是 R（`POSE` + 原耳角度）。
第 1 轮的批评原文、第 2 轮的三张盲排图与答案表都在 `proof/gate-d/`。

## 交用户的三选一

1. **照现状交**（R 版）：两人都说"最像活的"，外部参照稳定压过 1 个国际级 IP。
2. **再改一版**：合并 Q 的耳角度（更竖更大）——但两位评委对这一点意见相反，等于赌一边。
3. **换命题**：不做谛听 IP，改投同一赛事的第二轮视频（要等入围，或另找赛道）。
