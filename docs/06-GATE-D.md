# 06 · 闸 D：盲排（预先登记的判据与做法）

## 为什么不是「和往届得奖作混排」

这场大赛是**首届**，没有任何往届得奖作品。父单的闸 D 判据（成品与 ≥5 件往届得奖作混排，
每位评委都要把它排在 ≥3 件得奖作之上）在这里**无法照抄**。

上一轮（赛道 W）遇到同样情况时记下的教训是：**尺子要对齐媒介与画幅**。
所以这一轮用两条代理判据，**在看结果之前写下来**：

| 判据 | 内容 | 过线 |
| --- | --- | --- |
| P1 同题 | 同一角色三个版本（耳的大小与角度不同）A/B/C，3 位不同家族的评委会各自排序 | 定稿版至少被 **2 位**排在第 1 |
| P2 外部参照 | 定稿版与 5 个已成名的华人市场 IP 主形象混排（6 张，随机字母） | 定稿版排进 **前 3 名**（即压过 3 张） |

- P1 与 P2 都满足 → **过线**。
- 只满足一条 → **条件性通过**，写明差在哪。
- 都不满足 → **未过线**，照「两轮就停」的规则停手交用户。

**这 5 张不是同一场比赛的往届得奖作**，媒介也不一致（实拍照片 / 渲染 / 插画）。
P2 只能说明"放在成名 IP 旁边会不会立刻掉档"，不能直接换算成"进得了终评"。
这一点写在结论里，不藏。
